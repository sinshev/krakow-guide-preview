# Геопозиция отключена

## Назначение
Состояние, когда геопозиция недоступна, но маршрут всё ещё можно пройти вручную.

## На какой вопрос отвечает экран
Что будет работать без геопозиции и как включить её обратно?

## Компоновка и иерархия
- Сверху находятся заголовок и одна короткая строка.
- Внизу остаются действия ручного продолжения и открытия настроек.
- Лист по общему правилу листов: иконка, заголовок и текст у левого края; «×» нет — выход кнопка ручного продолжения (нажатие на затемнение, свайп вниз за ручку и системное «Назад» действуют так же).

## Блоки контента
- Заголовок.
- Короткое пояснение.
- Кнопки ручного продолжения и открытия настроек.

## Действия
- Продолжить маршрут вручную.
- Открыть настройки.

## Состояния / динамические данные
- Ограничиваются только текущее положение на карте и подсказки рядом (в том числе уведомления об остановке при выключенном экране).
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Состояние показывается листом по размеру содержимого (без пустой полосы) с небольшой линейной иконкой вместо рисунка с силуэтом города: геопозиция с чертой. Рисунок остаётся только у успешных состояний.
- Название: «Геопозиция не разрешена» / «Location is not allowed» (слово «Запрещено» не используется).

## Чего не должно быть
- Нельзя блокировать сам маршрут, если геопозиция отключена.
- Нельзя преувеличивать последствия отключения геопозиции.
