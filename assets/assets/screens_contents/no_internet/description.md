# Нет интернета

## Назначение
Общий экран отсутствия сети для тех сценариев, где без интернета нельзя продолжить покупку, восстановление или обновление данных.

## На какой вопрос отвечает экран
Что сейчас всё ещё работает, а для чего нужен интернет?

## Компоновка и иерархия
- Сверху находятся заголовок и одна короткая строка.
- Внизу остаются действия возврата в контекст входа и повтора.

## Блоки контента
- Заголовок.
- Короткое пояснение.
- Кнопки возврата в контекст входа и повтора.

## Действия
- Вернуться в контекст входа: лист открывается поверх экрана, который его вызвал, и «Назад» закрывает его, возвращая на этот экран (обычно Главная или экран маршрута). Если вызывающего экрана нет, «Назад» ведёт в контекст входа по ссылке.
- Повторить попытку.

## Состояния / динамические данные
- Экран используется только в онлайн-зависимых сценариях.
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Состояние показывается листом по размеру содержимого (без пустой полосы) с небольшой линейной иконкой вместо рисунка с силуэтом города: облако с перечёркивающей чертой. Рисунок остаётся только у успешных состояний.
- Вторичное действие называется «Закрыть» / «Close» вместо безымянного «Назад»; это и есть выход из листа, поэтому «×» нет (нажатие на затемнение, свайп вниз за ручку и системное «Назад» закрывают лист так же). Иконка, заголовок и текст у левого края, как у всех листов.
- Если под листом нет экрана (глубокая ссылка, холодный старт, сброс стека после покупки), под затемнением рисуется экран, с которого он открыт (`returnTo`: Routes, Home), если он известен, а не сплошной цвет.

## Чего не должно быть
- Нельзя скрывать, что купленные и скачанные маршруты остаются доступны.
- Нельзя обещать действия, которые без сети не сработают.
