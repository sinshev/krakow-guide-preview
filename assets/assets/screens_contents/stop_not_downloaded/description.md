# Контент точки не загружен

## Назначение
Состояние для offline-контекста, когда пользователь открыл точку, но офлайн-файлы маршрута ещё не загружены полностью.

## На какой вопрос отвечает экран
Почему эта точка недоступна без сети и что сделать дальше?

## Компоновка и иерархия
- Сверху находятся заголовок и одна короткая строка. Строка не повторяет заголовок: онлайн она объясняет, что точка входит в маршрут, которого нет на устройстве; без сети прямо говорит, что скачать маршрут сейчас нельзя, пока не появится интернет.
- Внизу остаются действия возврата к маршруту и главное действие, которое зависит от сети: онлайн это «Скачать маршрут», без сети это «Повторить» (загрузка без сети невозможна и не предлагается).
- Лист по общему правилу листов: иконка, заголовок и текст у левого края; «×» нет — выход «Назад к маршруту» (нажатие на затемнение, свайп вниз за ручку и системное «Назад» действуют так же).

## Блоки контента
- Заголовок.
- Короткое пояснение.
- Кнопки возврата к маршруту и главного действия («Скачать маршрут» онлайн, «Повторить» без сети).

## Действия
- Вернуться к маршруту.
- Онлайн: открыть загрузку маршрута.
- Без сети: «Повторить» заново проверяет соединение. Сеть появилась: открывается загрузка. Сети всё ещё нет: строка меняется на «Сети всё ещё нет…», лист остаётся.

## Состояния / динамические данные
- Состояние зависит от локального статуса загрузки текущего маршрута.
- Это состояние используется только в offline-контексте, когда локального bundle нет.
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Состояние показывается листом по размеру содержимого (без пустой полосы) с небольшой линейной иконкой вместо рисунка с силуэтом города: облако со стрелкой скачивания (есть сеть) или облако с чертой (нет сети). Рисунок остаётся только у успешных состояний.

## Чего не должно быть
- Нельзя терять связь с исходным маршрутом.
- Нельзя обещать доступ к точке без полной нужной загрузки.
- Нельзя делать это состояние default stop flow при наличии сети.
