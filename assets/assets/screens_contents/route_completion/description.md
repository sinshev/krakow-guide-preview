# Маршрут завершён

## Назначение
Короткий экран завершения прогулки. Он должен мягко завершить сценарий и дать один понятный следующий шаг.

## На какой вопрос отвечает экран
Что дальше после завершения маршрута?

## Компоновка и иерархия
- По центру: отметка-галочка в круге главного цвета, заголовок «Вы прошли маршрут» с названием маршрута, крупное «6 из 6» с подписью «остановок пройдено» и, только если в каталоге есть ещё не купленный маршрут, одна карточка «Следующая прогулка».
- Внизу одна кнопка «На главную». Подложка кнопки сплошная (цвет фона), рисунок города заканчивается над ней, поэтому кнопка не лежит на линиях рисунка.

## Блоки контента
- Главный заголовок «Вы прошли маршрут» / «You finished the walk» и название пройденного маршрута.
- Сводка только из локальных данных: крупное «2 из 2» (`stops_big`) с подписью «остановок пройдено» (`stops_unit`, EN «stops visited»: подпись называет действие; форма по числу остановок маршрута) по отмеченным остановкам. Длины маршрута нет: она не итог прогулки и есть на карточке маршрута. Целая фраза «Пройдено 2 из 2 остановок» (`stops_visited`) читается экранным диктором. Время в пути не показывается: данные о прогулке не хранят момент её начала (только отмеченные остановки), а угадывать нельзя; строка остановок скрыта, если прогресса нет.
- Одна карточка «Следующая прогулка»: первый маршрут из каталога, который пользователь ещё не открыл (название, длительность, длина). Нажатие открывает его предпросмотр (Route Detail в состоянии locked, назад ведёт на этот экран). Если закрытых маршрутов нет, карточки нет. Под строкой длительности и длины маленькая контурная плашка с замком и ценой из магазина («19 PLN»; цена не клиентская: без цены от магазина плашки нет). Давления нет: плашка не кнопка, нажимается вся карточка. Без соцфункций и без «поделиться».
- Если прогулка закончена на последней остановке, а часть остановок пропущена, под числом вместо подписи «остановок пройдено» стоит честная фраза «Вы побывали на 4 из 6 остановок» (`stops_partial`); если пройдены все, текст прежний.
- Кнопка перехода на главный экран.

## Действия
- Вернуться на главный экран.
- Открыть предпросмотр следующего маршрута (необязательно).

## Состояния / динамические данные
- Экран показывается после завершения активного маршрута и может учитывать локальный прогресс пользователя. Прогулка завершается, когда пользователь завершил последнюю остановку (явная кнопка «Завершить прогулку»), даже если часть остановок пропущена. Повторный просмотр любой остановки завершённого маршрута его не открывает заново: новый заход начинает только «Начать заново».
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.

## Чего не должно быть
- Нельзя превращать завершение маршрута в длинный отчёт.
- Нельзя навязывать следующий маршрут без спокойного выхода: карточка одна, а «На главную» остаётся на месте.
- Нельзя ставить вторую кнопку рядом с «На главную»: каталог открывает вкладка «Маршруты».
