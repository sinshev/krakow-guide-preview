# Пока нет начатых маршрутов

## Назначение
Пустое состояние для главного экрана, когда пользователь ещё не начал ни одного маршрута.

## На какой вопрос отвечает экран
С чего начать, если прогулка ещё не начата?

## Компоновка и иерархия
- Центрированный блок (общий `KgEmptyState`): линейная иконка 64 pt, короткий заголовок и одна строка пояснения.
- Под ним кнопка вторичной ширины с переходом к списку маршрутов («Все маршруты»).

## Блоки контента
- Заголовок.
- Кнопка перехода к маршрутам.

## Действия
- Открыть список маршрутов.

## Состояния / динамические данные
- Экран показывается, когда у пользователя ещё нет начатого маршрута.

## Чего не должно быть
- Нельзя оставлять главный экран без понятного следующего шага.
