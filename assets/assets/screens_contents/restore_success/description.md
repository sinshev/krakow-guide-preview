# Покупки восстановлены

## Назначение
Экран-результат успешного восстановления покупок на устройстве.

## На какой вопрос отвечает экран
Что делать после успешного восстановления покупок?

## Компоновка и иерархия
- Сверху находятся заголовок (у левого края, как текст под ним) и кнопка закрытия «×» (у листа ровно одно видимое действие закрытия).
- Под заголовком одна строка называет, что именно восстановлено: «Восстановлено: Krakow in 3 Hours.» (до трёх маршрутов названиями через запятую, в порядке ответа сервера); если маршрутов больше трёх, только число («Восстановлено 5 маршрутов»; форма склоняется по общему правилу множественных чисел). Если лист открыт без восстановления (ссылка, холодный старт), остаётся общая строка «Ваши маршруты доступны.».
- Внизу остаётся одно понятное действие: открыть маршруты.
- Если восстановление запущено с формы покупки, этот лист (как и «Покупки не найдены», «Не удалось восстановить») заменяет форму, а не ложится поверх неё: на экране один лист. Набранные в форме адреса сохраняются в черновике (`purchaseFormDraftProvider`), так что форма, открытая заново, содержит их.

## Блоки контента
- Главный заголовок.
- Строка о восстановленном (названия маршрутов или их число).
- Кнопка перехода к маршрутам.

## Действия
- Открыть список маршрутов.
- Закрыть лист и вернуться туда, откуда пользователь пришёл.

## Состояния / динамические данные
- Экран получает список восстановленных покупок от магазина или локальной проверки доступа (идентификаторы маршрутов из результата последнего восстановления; названия берутся из каталога). Названия не придумываются: если название маршрута неизвестно, показывается число.
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Лист по размеру содержимого с рисунком (силуэт города): это успешное состояние.
- Если под листом нет экрана (глубокая ссылка, холодный старт, сброс стека после покупки), под затемнением рисуется экран Routes, а не сплошной цвет.

## Чего не должно быть
- Нельзя превращать экран в подробный отчёт о восстановлении.
- Нельзя скрывать понятный следующий шаг.
