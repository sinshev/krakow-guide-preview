# Список остановок активного маршрута

## Назначение
Короткий лист поверх карты, который помогает быстро увидеть структуру текущего маршрута и перейти к нужной остановке.

## На какой вопрос отвечает экран
Где я нахожусь в маршруте и какую остановку открыть сейчас?

## Компоновка и иерархия
- Лист открывается поверх карты.
- Сверху располагаются заголовок и действие закрытия.
- Основную часть занимает список остановок.
- Остальное управление происходит через сам список и жест закрытия листа.

## Блоки контента
- Действие закрытия.
- Заголовок листа.
- Список остановок. Каждая строка показывает ход прогулки: галочка (пройдена), бордовая точка с подписью «Сейчас» (текущая), пустой круг (впереди). Подпись «(текущая)» после названия не используется. Если прогулка ещё не начата, отметок нет.

## Действия
- Закрыть лист и вернуться к карте.
- Открыть выбранную остановку.

## Состояния / динамические данные
- Порядок остановок и текущая точка приходят из сессионной модели маршрута.

## Чего не должно быть
- Нельзя делать этот лист основной заменой карты.
- Нельзя перегружать его длинными описаниями остановок.
