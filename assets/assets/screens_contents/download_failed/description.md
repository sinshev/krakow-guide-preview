# Загрузка не удалась

## Назначение
Состояние ошибки загрузки маршрута. Оно должно предлагать только понятные действия: повторить попытку или вернуться к маршруту.

## На какой вопрос отвечает экран
Что делать, если загрузка маршрута не завершилась?

## Компоновка и иерархия
- Сверху находятся заголовок и одна короткая строка.
- Внизу — действия повтора и возврата к маршруту.
- Лист по общему правилу листов: иконка, заголовок и текст у левого края; «×» нет — выход возврат к маршруту (нажатие на затемнение, свайп вниз за ручку и системное «Назад» действуют так же).

## Блоки контента
- Заголовок.
- Короткое пояснение; если причина известна, пояснение называет её (соединение прервалось, не хватает места на устройстве, сервер ответил с ошибкой, скачанные файлы не прошли проверку целостности), иначе общий текст.
- Кнопки повтора и возврата к маршруту.

## Действия
- Повторить попытку загрузки: загрузка запускается сразу, лист загрузки маршрута открывается уже с прогрессом, второй раз нажимать «Скачать» не нужно. Без сети вместо этого открывается общий экран «Нет интернета»; его «Повторить» возвращает на этот экран, а «Назад» — к маршруту. Если попытка снова не удалась, снова открывается этот экран.
- Вернуться к маршруту; он остаётся доступен онлайн.

## Состояния / динамические данные
- Краткая причина берётся из типа ошибки, сохранённого менеджером загрузок (`DownloadBundle.transfer?.failureCause` — у повторной загрузки готовой копии это причина неудавшейся попытки, а не рабочей копии: сеть, место на устройстве, сервер, целостность файлов, неизвестно). Для фоновых передач системы ошибка файла приводится к тем же типам; загрузка, прерванная закрытием приложения и не восстановленная при запуске, при запуске помечается неудавшейся с неизвестной причиной.
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Состояние показывается листом по размеру содержимого (без пустой полосы) с небольшой линейной иконкой вместо рисунка с силуэтом города: облако с чертой, при нехватке места накопитель. Рисунок остаётся только у успешных состояний.

## Чего не должно быть
- Нельзя оставлять пользователя без следующего шага.
- Нельзя превращать это состояние в длинный технический отчёт.
