# Точка в офлайне

## Назначение
Состояние точки маршрута без сети, когда часть контента уже доступна локально, а часть может требовать полной загрузки маршрута.

## На какой вопрос отвечает экран
Что из контента точки доступно сейчас без сети и куда перейти дальше?

## Компоновка и иерархия
- Сверху находятся заголовок «Точка сохранена частично» и строка о том, что доступно (текст) и чего нет (аудио и часть фото до полной загрузки).
- Внизу остаются главное действие, которое можно выполнить прямо сейчас, и возврат к маршруту.
- Лист по общему правилу листов: иконка, заголовок и текст у левого края; «×» нет — выход возврат к маршруту (нажатие на затемнение, свайп вниз за ручку и системное «Назад» действуют так же).

## Блоки контента
- Заголовок.
- Короткая строка о том, что доступно.
- Главная кнопка: без сети «Читать текст» (открывает скачанный текст точки), с сетью «Скачать маршрут» (докачать аудио и фото). Если читать нечего, единственное действие — «Назад к маршруту».
- Кнопка возврата к маршруту.

## Действия
- Вернуться к маршруту.
- Прочитать скачанный текст точки (без сети).
- Открыть загрузку маршрута (с сетью).

## Состояния / динамические данные
- Доступность текста, аудио и изображений зависит от локальной загрузки текущего маршрута.
- Если данные экрана не загрузились, показывается общее состояние ошибки из `common` («Что-то пошло не так», кнопка «Повторить»). Тексты исключений и технические детали пользователю не показываются, они пишутся в журнал.
- Состояние показывается листом по размеру содержимого (без пустой полосы) с небольшой линейной иконкой вместо рисунка с силуэтом города: облако с чертой. Рисунок остаётся только у успешных состояний.

## Чего не должно быть
- Нельзя скрывать, какая часть контента уже доступна.
- Нельзя обещать отсутствующие офлайн-данные.
