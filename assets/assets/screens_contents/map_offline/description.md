# Карта в офлайне

## Назначение
Состояние карты без сети, когда маршрут уже доступен локально и может продолжаться по скачанным данным.

## На какой вопрос отвечает экран
Что остаётся доступным на карте без интернета?

## Компоновка и иерархия
- Основную часть занимает карта.
- Сверху или в заметной зоне обозначается офлайн-режим.
- Внизу остаются короткая сводка и действие продолжения. Без карты вместо неё показывается список скачанных остановок, он заканчивается над сводкой; отдельной кнопки «Остановки» нет, потому что список уже виден. Лишней надписи «Офлайн» над заголовком «Карта недоступна офлайн» нет.

## Блоки контента
- Карта.
- Индикатор офлайн-режима.
- Короткая строка, если без неё неясно состояние.
- Список остановок на экране и действие продолжения.

## Действия
- Открыть любую остановку из списка.
- Продолжить маршрут.

## Состояния / динамические данные
- Экран работает по локальным данным без обновления онлайн-контента.

## Чего не должно быть
- Нельзя делать вид, что карта обновляется из сети.
- Нельзя перегружать экран длинными техническими пояснениями.
