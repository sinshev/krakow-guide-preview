Повторная проверка серой подложки: в исходной версии карта загрузилась корректно. Наблюдение не выдаётся за воспроизведённую и исправленную постоянную ошибку; проверяется возврат на карту из остановки и плеера.

Заполнение медиаблоков: сохранено отображение фотографии в placeholder общей Hero-анимации, чтобы переход не оставлял пустую обложку. Проверяются возврат и загрузка; качество фотографий-заглушек не оценивается.

## Материалы ревью

- [Интерактивное сравнение](index.html): 33 пункта аудита, отдельные пары для каждого; ниже в выборе — полный набор из 52 Flutter-экранов, включая RU и текст 2×.
- [Опубликованный preview](https://sinshev.github.io/krakow-guide-preview/reviews/ui-ux-2026-11-16/#/app/home). Это отдельный путь в репозитории web preview. Исходная ветка `main` приложения не менялась.
- `en/route-ended-partial.png`: один и тот же завершённый маршрут с одной пропущенной точкой. До: обе точки отмечены и предлагается сброс. После: пропуск виден, доступно продолжение без потери результата.
- `before/web/map-accessibility.json` и `after/web/map-accessibility.json`: реальная семантика Google Maps. До — 10 безымянных целей для пяти остановок; после — 5 названных целей.

Первые 37 исходных Flutter-снимков сохранены перед изменениями. Дополнительные 15 пар получены из сохранённой копии исходников и итоговой версии с одинаковыми фикстурами. Для списка неполного маршрута в обеих версиях прокрутка приводит к блоку прогресса. Серые карты и значки отсутствующих изображений в Flutter-render — детерминированные заглушки тестовой платформы; настоящая карта снята отдельно в браузере.

В браузере зафиксированы маршрут `route-roskoshny-maximum`, первая остановка, GPS выключен, аудио на паузе. Пары `map`, `map-mini`, `routes`, `stop` сняты при окне 1280×800. Полные PNG имеют размер 2560×1600; `*-phone.png` — неизменённые пиксели области `(950,84)–(1610,1518)`. Разница времени аудио не является изменением UI.

Повторные переходы карта → остановка → карта и карта → полный плеер → карта сохранили улицы и пять пинов. В последнем состоянии проверены все 12 загруженных тайлов и доступные названия пяти маркеров. Старая серая карта при повторной проверке исходного preview не воспроизвелась.

Браузерная проверка обнаружила дополнительную реальную ошибку: после разового HTTP 503 на UI-файле повтор получал ошибочный Future из `CachingAssetBundle`. Неудачный файл теперь удаляется из кэша; два регрессионных теста проверяют успешную следующую попытку для описания экрана и файла подписи. Публичная версия после обновления загружает Home и основные сценарии.
